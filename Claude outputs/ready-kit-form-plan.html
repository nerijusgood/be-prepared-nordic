Switch on the contact form in about 75 minutes

Nine steps. Tick each one when it is done. Your ticks stay on this device only, so you can close the page and come back.

Have ready

  • A Google account for the Sheet (the account that will own the messages)
  • Your Vercel login (the personal account nerijusgood)
  • The Terminal app on your Mac, and a password manager or a private note

Never

  • Paste the secret into a chat, a file in the repo, or a screenshot
  • Commit a .env file
  • Share the Sheet with anyone

  1. 1
    Vercel10 min

    Put the site on Vercel

    1. Open vercel.com/new and sign in with GitHub.
    2. Pick the repo nerijusgood/be-prepared-nordic and click Import.
    3. Set Framework Preset to Other. Leave Build Command and Output Directory empty.
    4. Click Deploy and wait for the confetti.

    Done when the vercel.app link opens the site.

    Claude can do this step for you through the Vercel connection. Say so in the morning.

  2. 2
    Google10 min

    Create the Sheet and add the script

    1. Open sheets.new and name the file Ready Kit messages.
    2. Click Extensions, then Apps Script.
    3. Delete the sample code. Paste the full content of docs/google-sheet-Code.gs from the repo. Click Save.
    4. In the function list choose setup and click Run.
    5. Google asks for access. If it says the app is not verified, click Advanced, then Go to the project, then Allow. This is your own script.

    Done when the Sheet has a tab called Messages with 7 headers.

  3. 3
    TerminalGoogle5 min

    Make a secret and save it in the script

    1. Run this in Terminal. It prints a long random text.
    openssl rand -hex 24
    1. Save that text in your password manager. You need it again in step 5.
    2. In Apps Script click the gear (Project Settings). Scroll to Script Properties and click Add script property.
    3. Name: SECRET. Value: the random text. Click Save script properties.
    Do not send the secret to Claude. Claude never needs to see it.

    Done when Script Properties lists SECRET.

  4. 4
    Google7 min

    Publish the script as a web app

    1. Click Deploy, then New deployment. Click the gear and choose Web app.
    2. Execute as: Me. Who has access: Anyone. The secret protects it.
    3. Click Deploy and copy the Web app URL. It ends with /exec.
    4. Keep the URL in a private note for step 5.
    If you open the URL in a browser, you see an error about doGet. That is normal. The script only accepts messages from the website.

    Done when you have a URL that ends with /exec.

  5. 5
    Vercel8 min

    Give Vercel the two values and redeploy

    1. In your Vercel project open Settings, then Environment Variables.
    2. Add SHEET_WEBHOOK_URL with the Web app URL from step 4.
    3. Add SHEET_SECRET with the random text from step 3. Turn on Sensitive if Vercel offers it.
    4. Select Production and Preview for both. Click Save.
    5. Open Deployments, click the three dots on the latest one, and choose Redeploy.
    SHEET_WEBHOOK_URL SHEET_SECRET

    Done when the new deployment says Ready. A change to a variable only works after a redeploy.

  6. 6
    TerminalGoogle10 min

    Send a test message

    1. Replace YOUR-SITE.vercel.app with your real address in both places, then run the command.
    curl -s -X POST https://YOUR-SITE.vercel.app/api/contact \
  -H 'Content-Type: application/json' \
  -H 'Origin: https://YOUR-SITE.vercel.app' \
  -d '{"subject":"other","email":"test@example.com","message":"Hello, this is a test message","consent":true,"website":"","elapsed":9000,"lang":"en"}'
    1. You must see {"ok":true}.
    2. Open the Sheet. A new row appears with Status New.
    3. Now send one message from the real form on the site.

    Done when the Sheet has one row from the command and one from the form.

    Claude reads the Vercel runtime logs if anything fails. See the fix table below.

  7. 7
    Google3 min

    Turn on the 12-month clean-up

    1. In Apps Script click the clock icon (Triggers), then Add Trigger.
    2. Function: purgeOld. Event source: Time-driven. Type: Month timer. Pick any day and time. Click Save.

    Done when the trigger shows in the list. The privacy notice promises deletion after 12 months, so this step matters.

  8. 8
    Vercel10 min

    Add a rate limit for the form

    1. In your Vercel project open Firewall, then add a new rule. Name it Limit contact form.
    2. Condition: Request Path equals /api/contact.
    3. Action: Rate limit. For example 5 requests per 1 minute for each IP address. When the limit is reached: Deny.
    4. Save the rule, then publish the changes.
    Menu names can change. If the rate limit option is missing on the Hobby plan, tell Claude. The function has its own limit of 5 per hour as a backup.

    Done when the rule shows as active in the Firewall page.

    2. In the Sheet, check that the new row says language da.
    3. Delete all test rows from the Sheet.
    4. Read the privacy notice once more: your name and the 12-month rule. Tell Claude if the wording needs a change.

    Done when the Sheet is empty and you are happy with the notice.

If something fails

The function answers with a short code. These are the real ones from the code.

Form shows an error, code "config"Vercel has no SHEET_WEBHOOK_URL or SHEET_SECRET, or you did not redeploy after adding them. Repeat step 5.
Code "store" (HTTP 502)The Sheet script said no. The secret differs between Vercel and Apps Script, the URL is wrong, or access is not set to Anyone. Check steps 3 and 4. Claude can read the Vercel log line that starts with contact:.
Code "origin" (HTTP 403)The command had no Origin header, or the Origin differs from the site address. Copy the command again and replace both addresses.
Code "rate" (HTTP 429)You tried more than 5 times in one hour. Wait, or test from another network.
Answer is ok but no row appearsThe function hides spam by answering ok. It does this when elapsed is under 2500 or website is not empty. Use the command exactly as shown.
Codes "email", "message", "consent", "links"The test data failed a check. The message needs 10 or more letters, a valid email, consent true, and at most 2 links.
